# À propos des captures d'écran

Ce dossier contiendra des captures d'écran de l'application NionFar pour illustrer le README.

Pour ajouter vos captures d'écran :

1. Prenez des captures d'écran des pages importantes de l'application
2. Nommez-les de manière descriptive (ex: home.png, explorer.png, etc.)
3. Placez-les dans le dossier `screenshots/`
4. Mettez à jour les références dans le README.md si nécessaire

Suggestions de captures d'écran à ajouter :
- Page d'accueil (home.png)
- Page Explorer (explorer.png)
- Filtres sur mobile (filter-mobile.png)
- Vue en liste (list-view.png)
- Vue en grille (grid-view.png)
- Détails d'un service (service-details.png)

Note : Les dimensions recommandées sont d'environ 1200x800px pour les captures d'écran de bureau et 375x812px pour les captures d'écran mobiles.
