# NionFar.sn

Plateforme de freelance pour connecter les talents sénégalais avec des clients locaux et internationaux.

## Description

NionFar est une plateforme de services freelance conçue spécifiquement pour le marché sénégalais. Elle permet aux freelances de proposer leurs services, gérer leurs commandes, communiquer avec leurs clients et recevoir des paiements en toute simplicité.

## Fonctionnalités

- **Tableau de bord** : Statistiques et vue d'ensemble pour les freelances
- **Gestion des commandes** : Suivi complet du cycle de vie des commandes
- **Messagerie** : Système de conversation en temps réel avec les clients
- **Gestion des services** : Création et modification de services à proposer
- **Paiements** : Suivi des revenus et système de retrait
- **Système de notification** : Alertes pour les nouvelles commandes, messages et paiements

## Technologies utilisées

- Next.js (React)
- TypeScript
- Tailwind CSS
- React Icons

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/Sabrsl/nion_farr.git
cd nion_farr

# Installer les dépendances
npm install

# Lancer l'application en mode développement
npm run dev
```

## Structure du projet

- `/frontend` : Interface utilisateur de l'application
  - `/pages` : Pages de l'application Next.js
  - `/components` : Composants réutilisables
  - `/data` : Données de démonstration
  - `/types` : Définitions de types TypeScript
  - `/styles` : Feuilles de style CSS
